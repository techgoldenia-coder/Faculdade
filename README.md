## Organização

Por **matéria**, não por semestre — o semestre fica registrado no `INFO.md` de cada uma.

```
<Nome da matéria>/
├── INFO.md           semestre, professor, ementa, avaliações, notas
├── Base de dados/    material de consulta (PDFs das unidades, artigos)
└── ...               trabalhos, anotações e resumos soltos na raiz
```

Pastas de apoio: `0 - Institucional/` (normas ABNT, grade, banco de referências) e
`1 - Modelos/` (modelos para copiar ao abrir matéria ou trabalho novo).
